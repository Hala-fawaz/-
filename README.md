🕌 رسالة | Risalah

«موقع تفاعلي مدعوم بالذكاء الاصطناعي لاستكشاف السيرة النبوية والتاريخ الإسلامي من خلال تجربة رقمية تفاعلية، متعددة اللغات، وقائمة على مصادر معرفية موثوقة.»

---

📖 عن المشروع

رسالة هو موقع إلكتروني تفاعلي يهدف إلى تقديم تجربة رقمية حديثة لاستكشاف أهم الأحداث والمحطات والأماكن المرتبطة بالسيرة النبوية والتاريخ الإسلامي.

يجمع الموقع بين الذكاء الاصطناعي، والاسترجاع المعزز بالتوليد (RAG)، والترجمة متعددة اللغات، وقاعدة معرفية للمصادر التاريخية؛ لتحويل المعلومات التاريخية من مصادر وكتب متفرقة إلى تجربة تفاعلية سهلة الوصول والاستكشاف.

يهدف المشروع إلى جعل المعرفة التاريخية أكثر سهولة، تفاعلاً، ووضوحًا لمستخدمين من خلفيات ولغات مختلفة.

---

🎯 المشكلة

توجد المعرفة التاريخية والسيرة النبوية في العديد من الكتب والمصادر والوثائق، مما قد يجعل الوصول إلى المعلومات المناسبة وفهمها في سياقها أمرًا صعبًا.

ومن أبرز التحديات:

- صعوبة الوصول السريع إلى المعلومات التاريخية الموثوقة.
- تشتت المعلومات بين مصادر متعددة.
- صعوبة فهم تسلسل الأحداث وربطها بالأماكن.
- محدودية المحتوى التفاعلي مقارنة بالمصادر التقليدية.
- اختلاف لغات المستخدمين وحاجتهم إلى الوصول إلى المعرفة بلغتهم.

---

💡 الحل

يقدم رسالة تجربة تفاعلية تسمح للمستخدم باستكشاف المحطات والأماكن التاريخية بطريقة رقمية.

فعند استكشاف موقع تاريخي مثل مكة المكرمة، يمكن للمستخدم الوصول إلى معلومات مرتبطة بالمكان والأحداث التاريخية المتعلقة به، مع الاستفادة من الذكاء الاصطناعي لتقديم تجربة أكثر تفاعلاً.

يعتمد المشروع على:

- 🗺️ استكشاف تفاعلي للمحطات والأماكن التاريخية.
- 🤖 مرشد تاريخي مدعوم بالذكاء الاصطناعي.
- 📚 قاعدة معرفية للمصادر.
- 🔎 تقنية الاسترجاع المعزز بالتوليد (RAG).
- 🌍 ترجمة مدعومة بالذكاء الاصطناعي.
- 📖 الاعتماد على مصادر معرفية تاريخية.
- 🏛️ ربط الأحداث بالأماكن والمحطات التاريخية.

🤖 المرشد التاريخي الذكي

يهدف رسالة إلى توفير مرشد تاريخي مدعوم بالذكاء الاصطناعي يتفاعل مع المستخدم أثناء استكشافه للمواقع التاريخية.

فعلى سبيل المثال، عند اختيار مكة المكرمة، يستطيع النظام تقديم معلومات تاريخية مرتبطة بالمكان والاستفادة من قاعدة المعرفة لإرجاع المعلومات ذات الصلة.

الهدف هو الانتقال من مجرد عرض النصوص إلى تجربة تفاعلية يقودها الذكاء الاصطناعي.

🔎 الاسترجاع المعزز بالتوليد — RAG

تعمل العملية بالشكل التالي:

المصادر التاريخية
       ↓
    ملفات PDF
       ↓
   استخراج النص
       ↓
     تقسيم النص
       ↓
 إنشاء Embeddings
       ↓
   تخزين المتجهات
       ↓
    الاسترجاع
       ↓
المعلومات ذات الصلة
       ↓
    المرشد الذكي

تساعد هذه التقنية النظام على البحث عن المعلومات المرتبطة بالسؤال من المصادر المتاحة قبل استخدامها في تكوين الإجابة.

🚀 تشغيل المشروع

المتطلبات

تأكد من تثبيت:

- Python 3.11 أو أحدث
- Node.js
- npm
- Git

---

1️⃣ تحميل المشروع

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git

ثم:

cd رسالة

---

2️⃣ إعداد الـ Backend

انتقل إلى مجلد Backend:

cd backend

أنشئ بيئة افتراضية:

python -m venv .venv

فعّل البيئة الافتراضية في Windows:

.venv\Scripts\Activate.ps1

ثم ثبت المتطلبات:

pip install -r requirements.txt

---

3️⃣ تشغيل الـ Backend

من داخل مجلد "backend":

uvicorn app.main:app --reload

سيعمل الخادم على:

http://127.0.0.1:8000

ويمكن الوصول إلى توثيق الـ API من:

http://127.0.0.1:8000/docs

---

4️⃣ تشغيل الموقع

افتح نافذة Terminal جديدة وانتقل إلى:

cd frontend

ثبت الحزم:

npm install

ثم شغّل الموقع:

npm run dev

سيكون الموقع متاحًا على:

http://localhost:3000

📚 قاعدة المعرفة

تحتوي قاعدة المعرفة على المصادر التاريخية التي يتم استخدامها ضمن نظام RAG.

تمر المصادر بعدة مراحل:

1. استخراج النص من ملفات PDF.
2. تقسيم النص إلى أجزاء صغيرة.
3. إنشاء التمثيلات المتجهية Embeddings.
4. تخزينها في قاعدة المتجهات.
5. البحث عن المعلومات الأكثر ارتباطًا بالسؤال.
6. تمرير المعلومات المسترجعة إلى نظام الذكاء الاصطناعي.

يساعد هذا الأسلوب على جعل إجابات النظام مرتبطة بالمصادر الموجودة في قاعدة المعرفة بدل الاعتماد فقط على المعرفة العامة للنموذج.
