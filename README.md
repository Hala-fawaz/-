رسالة | Risalah

موقع تفاعلي مدعوم بالذكاء الاصطناعي لاستكشاف السيرة النبوية والتاريخ الإسلامي من خلال تجربة رقمية تفاعلية، متعددة اللغات، وقائمة على مصادر معرفية موثوقة.

⸻

عن المشروع

رسالة هو موقع إلكتروني تفاعلي يهدف إلى تقديم تجربة رقمية حديثة لاستكشاف أبرز الأحداث والمحطات والأماكن المرتبطة بالسيرة النبوية والتاريخ الإسلامي.

يجمع المشروع بين تقنيات الذكاء الاصطناعي، والاسترجاع المعزز بالتوليد (RAG)، والترجمة متعددة اللغات، وقاعدة معرفية للمصادر التاريخية؛ بهدف تحويل المعلومات التاريخية المتفرقة في الكتب والمصادر إلى تجربة رقمية تفاعلية وسهلة الوصول والاستكشاف.

يسعى المشروع إلى جعل المعرفة التاريخية أكثر سهولة ووضوحًا وتفاعلًا، مع إتاحتها للمستخدمين من خلفيات ولغات مختلفة.

⸻

المشكلة

تتوزع المعلومات المتعلقة بالسيرة النبوية والتاريخ الإسلامي بين العديد من الكتب والمصادر والوثائق، مما قد يجعل الوصول إلى المعلومات المناسبة وفهمها ضمن سياقها التاريخي أمرًا صعبًا.

وتتمثل أبرز التحديات في:

* صعوبة الوصول السريع إلى المعلومات التاريخية الموثوقة.
* تشتت المعلومات بين مصادر متعددة.
* صعوبة تتبع تسلسل الأحداث وربطها بالأماكن التاريخية.
* محدودية التجارب التفاعلية مقارنة بالمصادر التقليدية.
* اختلاف لغات المستخدمين والحاجة إلى توفير المعرفة بلغات متعددة.

⸻

الحل

يقدم رسالة تجربة رقمية تفاعلية تساعد المستخدم على استكشاف الأحداث والمحطات والأماكن التاريخية بطريقة مترابطة.

يعتمد المشروع على مجموعة من التقنيات التي تعمل معًا لتقديم تجربة معرفية متكاملة، تشمل:

* استكشاف تفاعلي للمحطات والأماكن التاريخية.
* مرشد تاريخي مدعوم بالذكاء الاصطناعي.
* قاعدة معرفية للمصادر التاريخية.
* تقنية الاسترجاع المعزز بالتوليد (RAG).
* نظام ترجمة متعدد اللغات مدعوم بالذكاء الاصطناعي.
* الاعتماد على مصادر معرفية وتاريخية.
* ربط الأحداث بالمواقع والمحطات التاريخية.

تشغيل المشروع

المتطلبات

قبل تشغيل المشروع، يجب التأكد من تثبيت:

* Python 3.11 أو أحدث
* Node.js
* npm
* Git

⸻

تحميل المشروع

git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git

ثم الانتقال إلى مجلد المشروع:

cd رسالة

⸻

إعداد Backend

الانتقال إلى مجلد Backend:

cd backend

إنشاء بيئة افتراضية:

python -m venv .venv

تفعيل البيئة الافتراضية في Windows:

.venv\Scripts\Activate.ps1

تثبيت المتطلبات:

pip install -r requirements.txt

من داخل مجلد backend:

uvicorn app.main:app --reload

سيعمل الخادم على:

http://127.0.0.1:8000

ويمكن الوصول إلى توثيق واجهة API من:

http://127.0.0.1:8000/docs

مرشد رِسالة (الإجابة عن الأسئلة من كتب السيرة)

يجيب المرشد عبر POST /api/guide بإرسال:

{"question": "ماذا حدث في غزوة بدر؟", "station": "غزوة بدر — بدر"}

الحقل station اختياري: ترسله صفحة المحطة ليفهم المرشد أسئلة مثل «ما الأماكن المهمة في المحطة؟». وإضافة "debug": true تُظهر المقاطع المختارة واسم النموذج.

كيف يعمل:
1. يُبنى فهرس بحث (SQLite FTS5) من ملفات backend/knowledge/sources بعد توحيد الكتابة العربية (إزالة التشكيل، توحيد الألف والتاء المربوطة، فصل «و/ب/ال»...).
2. يحدد المرشد كلمات السؤال المهمة، ويستبعد أدوات السؤال وفعل السؤال («حدث»، «صار»...).
3. يرتب المقاطع حسب تغطيتها للسؤال وعنوان الفصل الذي تقع فيه، ويختار مقاطع متنوعة من كتب مختلفة.
4. يكتب «راوي رِسالة» الإجابة من هذه المقاطع فقط، بأسلوب سردي، ويُتحقق في الكود من أن أي آية أو حديث بين علامتي تنصيص موجود حرفيًا في المصادر.

بناء الفهرس (مرة بعد كل تعديل في المصادر، ويستغرق نحو دقيقتين، وحجمه نحو 600 ميغابايت ولا يُرفع إلى git):

python -m app.rag.fts_builder

إن لم يكن الفهرس موجودًا يبنيه الخادم تلقائيًا في الخلفية عند التشغيل، ويرد المرشد خلال ذلك برسالة «جاري تجهيز فهرس المصادر».

متغيرات البيئة (في backend/.env أو في إعدادات Render):

GROQ_API_KEY           مطلوب
GROQ_MODEL             النموذج الأساسي، الافتراضي openai/gpt-oss-120b
GROQ_FALLBACK_MODEL    نموذج احتياطي عند فشل الأساسي، الافتراضي allam-2-7b (اكتب none لإيقافه)
RAG_VERIFY_ANSWERS     1 لتفعيل تدقيق ثانٍ للإجابة بنداء إضافي للنموذج، الافتراضي 0
RAG_AUTO_BUILD_INDEX   0 لإيقاف البناء التلقائي للفهرس عند التشغيل، الافتراضي 1

النشر على Render: اجعلوا Build Command:

pip install -r requirements.txt && python -m app.rag.fts_builder

إضافة مصادر: ضعوا ملف .txt في backend/knowledge/sources ثم أعيدوا بناء الفهرس. يدعم المحمّل صيغة تصدير المكتبة الشاملة (بعلامات «(ص: N)»)، وصيغة المحطات المرقمة مثل journey-events.txt، وأي نص عادي.

الاختبارات (لا تحتاج مفتاحًا ولا الفهرس الكامل):

python -m unittest discover -s tests -p "test_rag_*.py"

وتقييم المرشد على 26 سؤالًا من السيرة بعد بناء الفهرس:

python tests/eval_guide_questions.py
python tests/eval_guide_questions.py --llm

قاعدة المعرفة

تحتوي قاعدة المعرفة على المصادر التاريخية المستخدمة ضمن نظام RAG.

تمر المصادر بعدة مراحل لمعالجتها وتجهيزها للبحث والاسترجاع:

1. استخراج النص من ملفات PDF.
2. تقسيم النص إلى أجزاء صغيرة.
3. إنشاء التمثيلات المتجهية Embeddings.
4. تخزين التمثيلات في قاعدة المتجهات.
5. البحث عن المعلومات الأكثر ارتباطًا بالسؤال.
6. تمرير المعلومات المسترجعة إلى نظام الذكاء الاصطناعي.

يساعد هذا الأسلوب على ربط إجابات النظام بالمصادر الموجودة في قاعدة المعرفة بدل الاعتماد بشكل كامل على المعرفة العامة للنموذج.
