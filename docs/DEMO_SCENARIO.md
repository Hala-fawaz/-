# Demo Scenario

## Objective
Demonstrate the main user journey of the Risalah platform in a short and clear sequence.

## Demo Flow

1. Open the Risalah platform.
2. Select the preferred language.
3. Open the Interactive Atlas.
4. Navigate to the first historical station.
5. Display the station information and timeline.
6. Ask the AI guide a historical question.
7. Show the grounded answer with source references.
8. Change the output language.
9. Confirm that the answer is translated while the source reference remains attached.
10. Ask a fiqh/ruling question.
11. Confirm that the AI Router activates the safety/abstention behavior.
12. Navigate to another historical station.
13. End the journey with the modern global view.

## Example Historical Question
How did Islam spread to Southeast Asia?

## Expected Demo Result
- The atlas works correctly.
- Historical stations can be explored.
- The AI returns grounded answers.
- References are displayed.
- Translation works correctly.
- Safety routing works for fiqh questions.
